# Ratatouille (Asobo) AutoSplitter

A LiveSplit autosplitter and load remover for **Asobo Studio's Ratatouille**.
<p>All versions except russian are known to be supported.</p>

## How to use

### Setup From LiveSplit
Right click and go to "Edit splits".
Set the game name to Ratatouille (Asobo).
Press the activate button below.

### Manual Setup
Download the asl file.
Inside of LiveSplit, right click and go to "Edit Layout".
Press the plus icon and navigate to: Control -> Scriptable Auto Splitter.
Double click on it, select browse and choose the asl file.

- The autosplitter is setup to work with standard splits.
 If you want to use modified splits, be sure to change the autosplitting configuration.

## Troubleshooting
- Make sure to only run one instance of the autosplitter at a time.
- Remove any installed mods
